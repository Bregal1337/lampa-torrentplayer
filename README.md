# Торренты TV для Lampa

Плагин для [Lampa](https://github.com/yumata/lampa-source), который делает просмотр торрентов на телевизоре удобным с пульта.

## Установка

Lampa → Настройки → Расширения → «Добавить плагин» → адрес:

```
https://bregal1337.github.io/tv.js
```

Файл публикуется через GitHub Pages (репозиторий [bregal1337.github.io](https://github.com/Bregal1337/bregal1337.github.io)): после обновления новая версия доступна через несколько минут, Lampa подхватит её при следующем запуске.

Нужны настроенные в Lampa парсер (JacRed или Jackett) и TorrServer.

## Что умеет

**Экран сериала** (открывается кнопкой «Торренты» на карточке)
- сезоны с постерами, числом раздач и прогрессом просмотра;
- серии с кадрами из TMDB, длительностью, датой выхода и отметками «✓» / «▶ 23:15»;
- «▶ Продолжить с …» и «С начала»; при открытии фокус сразу на серии, где вы остановились;
- выбор озвучки и качества — плагин сам подбирает лучшую раздачу сезона, её можно сменить. Озвучка и качество отсекают друг друга: выбрали озвучку — в качестве остаются только те, что у неё есть, выбрали качество — в озвучках только те, что есть в этом качестве; «Любая» и «Любое» снимают выбор;
- серия берётся из той раздачи, где она есть: сезон разложен по нескольким раздачам («Блич», 1 сезон: 1–167 в одной, 168–366 в другой) — для каждой серии плагин сам выбирает лучшую из тех, где она есть, той же озвучки и качества (у выбранной вручную раздачи — сначала её продолжение той же студии) и показывает её справа. «Нет в раздаче» — только если серии нет ни в одной раздаче сезона, «другая озвучка» — если она есть только в другой озвучке;
- среди озвучек — «Оригинал + субтитры» (сразу после дубляжа): раздачи с дорожкой на языке оригинала и русскими субтитрами — по реальным дорожкам (ffprobe из JacRed) или по названию («Original + Sub Rus», «JAP+Sub», «СТ»). Дорожку и субтитры включайте в плеере: внешний плеер сам выбирает, что играть;
- OK на серии сразу запускает её: плагин находит нужный файл в TorrServer, плеер получает плейлист следующих серий;
- долгое OK — «С начала», «Отметить просмотренной», «Выбрать файл вручную»;
- раздача одного сезона («2 сезон», «[S02]», «Название 2»), а в именах файлов сезона нет («Cyberpunk Edgerunners - 01.mkv»): Lampa считала бы их 1-м сезоном — с названиями и кадрами 1-го сезона и прогрессом туда же. Плагин относит все файлы такой раздачи к её сезону; раздача нескольких сезонов со сквозной нумерацией (1–20) раскладывается по числу серий сезонов;
- серии нет в файлах раздачи — плагин сам открывает следующую подходящую раздачу (той же озвучки, с сидами, до трёх попыток), а не останавливается на «не найдена». Если такая раздача за 30 секунд не отдала список файлов, загрузка отменяется с сообщением. Раздача, в которой при открытии не нашлось ни одного файла нужного сезона, в этом сезоне больше не предлагается;
- раздача одного сезона, а в именах файлов — другой сезон («2 сезон: Части 1-4: 1-48 серии из 50» с файлами «Bleach.Thousand-Year.Blood.War.S01E48» — стриминг считает «Тысячелетнюю войну» отдельным сериалом): если номера файлов сходятся с тем, что написано в названии раздачи, верит названию; без номеров в названии — файлам. Номер серии, который Lampa в имени не нашла («[AniDub]_BLEACH_300_[1280x720_x264]»), плагин находит сам;
- только что вышедший сезон: русские названия и описания в API TMDB появляются позже, чем на сайте («Эпизод 1…10»), — пока их нет, показываются английские, а вместо отсутствующих кадров — фон сериала.

**Экран фильма** — описание, выбор озвучки, качества и раздачи, «Смотреть» / «Продолжить».

**Субтитры**
- из самой раздачи: Lampa прикладывает к серии только файлы, в имени которых есть полное имя видео, а в аниме-раздачах субтитры часто названы иначе («Subs/Rus/[Crunchyroll] JJK S2 - 05.ass» к «[AniPlague] Jujutsu Kaisen - 05 [1080p].mkv»). Плагин подбирает их по номеру серии и сезону (папки [TV-1]/[TV-2], S2), русские — первыми, надписи — после полных, английские отбрасываются, если есть русские. Приложение Lampa передаёт их в MX Player (и в плейлисте — каждой серии свои), Just Player и MPV; в VLC приложение субтитры пока не передаёт;
- из интернета (OpenSubtitles): выбрано «Оригинал + субтитры», а в раздаче русских субтитров нет — перед запуском серии плагин ищет их на OpenSubtitles (по номеру серии TMDB, затем по номеру раздачи), берёт лучший вариант и отдаёт плееру прямую ссылку. Если лимит позволяет — и для следующей серии. Нужен свой бесплатный ключ: opensubtitles.com → профиль → API consumers → New consumer. Настройки → «Торренты TV» → «OpenSubtitles: ключ с телефона» — QR-код, на телефоне откроется файл `opensubtitles.txt` в вашем репозитории синхронизации: вставьте ключ после `api_key:`; логин и пароль OpenSubtitles — по желанию (без входа — 5 загрузок в сутки с одного IP, со входом — по лимиту аккаунта). Пароль хранится в этом файле приватного репозитория и в Lampa на устройстве. С ключом в «Оригинал + субтитры» попадают и раздачи с оригинальной дорожкой без субтитров, но раздачи со своими субтитрами выбираются первыми.

**Список раздач** («Все раздачи»)
- быстрые фильтры кнопками с числом раздач: качество, тип перевода, студия озвучки, сезон, источник, трекер, HDR/DV;
- студии и дорожки берутся из реальных звуковых дорожек (ffprobe из JacRed), а не только из названия;
- умная сортировка, «★ Лучший вариант», скрытие экранок, битрейт, 5.1/7.1, русские субтитры.

**Список файлов TorrServer** — серии плиткой с крупными кадрами.

**Продолжения под своим названием** — rutracker часто называет новый сезон «Cyberpunk: Edgerunners 2 / Киберпанк: Бегущие по краю 2», а JacRed ищет раздачи по точному названию сериала, и такие на обычный запрос не приходят. Для вышедших сезонов со 2-го (последних трёх) плагин спрашивает тот же JacRed ещё раз — «Название N» с годом сезона, а «Название 2» в имени раздачи считает 2-м сезоном.

**Несколько источников** — к парсеру Lampa можно добавить свои Jackett/JacRed (Настройки → «Торренты TV» → «Дополнительные источники», формат `адрес|ключ`, через запятую). Запросы идут параллельно, одинаковые раздачи склеиваются, у раздачи видно, откуда она пришла (⊕), неответивший источник не мешает остальным. Поиск rutor через TorrServer тоже подключается, но на ТВ с 2 ГБ не нужен: TorrServer с ним занимает +300–400 МБ.

**Досмотренные серии после внешнего плеера** — MX сам идёт по плейлисту и возвращает в Lampa позицию только последней серии, а если Android выгрузил Lampa посреди просмотра — ничего. TorrServer же помнит каждый файл, который открывал плеер. При запуске плагин запоминает, какой файл какая серия, а при следующем старте Lampa (и при возврате из плеера) спрашивает TorrServer, до какой серии дошёл плеер: все серии до неё отмечаются просмотренными, «Продолжить» встаёт на неё. Позицию внутри последней серии восстановить нельзя — её знает только плеер.

**Аниме: сезоны и части по Shikimori** (нужен плагин «Аниме», anime.js) — у Shikimori каждая часть сериала — отдельный тайтл с числом серий и датой выхода, а карта аниме знает, какой это сезон у трекеров. Плагин раскладывает серии TMDB по этим тайтлам по датам выхода; тайтлы одного сезона становятся его частями, в списке серий перед каждой частью — её название. «Блич»: 1 сезон — 366 серий, 2 сезон — «Тысячелетняя кровавая война» из четырёх частей (13 + 13 + 14 + 10), как на трекерах («2 сезон: Часть 2: 1-13 серии из 13», «[ТВ-2, часть 2]»). Раздача части считает серии с начала части — её файлы 01–13 ложатся на 14–26-ю серии сезона, а раздача «Части 1-3: 1-40» — с начала сезона. Сквозная нумерация («Ван-Пис [1061-1118]», «One Piece - 1061.mkv») переводится в сезон и серию, раздачи с сериями вне сезона в нём не показываются. Раздачи одного сезона с годами вне лет этого сезона (арки старого «Блича» 2005 года как «2 сезон») — тоже. Если TMDB режет сериал по годам, а трекеры считают сезонами тайтлы («Гинтама»: 11 сезонов TMDB, а у трекеров «ТВ-1» — это 201 серия, 1–4-й сезоны TMDB, «ТВ-2» — Gintama'), сезоны собираются по тайтлам — когда тайтлов несколько и раздачи сами называют сезоны; у «Ван-Писа» и «Наруто» (один тайтл, сквозные номера) остаются сезоны TMDB. Досмотренное уходит в Shikimori по частям. Без плагина «Аниме» или если тайтлы Shikimori не сходятся с сериями TMDB — сезоны по названиям раздач, как ниже.

**Аниме: сезоны как на трекерах (по названиям раздач)** — TMDB одни тайтлы делит на сезоны, а другие держит одним списком («Магическая битва»: 1 сезон, 59 серий; «Фрирен»: 38; «Звёздное дитя»: 35; Re:Zero: 85), а на трекерах это «1 сезон» (24), «2 сезон» / «ТВ-2» (23), «3 сезон» (12). Плагин берёт число серий каждого сезона из названий раздач («2 сезон: 1-23 серии из 23», «[ТВ-2] (23 из 23)», «[02x01-06 из 23]» — по большинству) и раскладывает серии TMDB по этим сезонам, уточняя границы по перерывам между датами выхода. Если сезоны TMDB и так совпадают с трекерами («Атака титанов», «Семья шпиона»), ничего не меняется. Работает для аниме и мультсериалов. Файлы в раздачах тоже сопоставляются: без сезона в имени («Jujutsu Kaisen - 05» в раздаче «2 сезон»), S02E05, папки [TV-1]/[TV-2] и сквозная нумерация 1–59 — прогресс пишется своей серии, в плеер уходят правильные названия.

**Удалить из истории** — долгое OK на карточке (в «Истории», на главной, в поиске) или кнопка «Закладки» на странице фильма → «Удалить из истории». Фильм или сериал пропадает из «Истории» и «Продолжить», прогресс всех серий сбрасывается, плагин забывает последнюю серию; закладки и выбранная озвучка остаются. С синхронизацией удаление уходит на остальные устройства человека. Обычная галочка «История» в том же меню убирает карточку только из списка, а прогресс оставляет.

**Телефон** — в портретной ориентации экран сериала идёт одной лентой: сезоны, кнопки с озвучкой и качеством, список серий. Первое касание серии выбирает её, второе — запускает.

## Синхронизация между устройствами (GitHub)

Переносит между телевизорами и телефоном одного человека: прогресс серий и фильмов, отметки «просмотрено», все закладки Lampa (Закладки, Нравится, Позже, История, Смотрю и т. д.), выбранные озвучку, качество, раздачу и последнюю серию.

Всё хранится в одном приватном репозитории: папка на человека, в ней файл на устройство. Устройство пишет только свой файл, читает все и берёт самое свежее, поэтому ТВ и телефон не затирают друг друга, а удалённые закладки не возвращаются.

**Один раз создать репозиторий и токен** (на телефоне или компьютере):

1. github.com/new → имя `lampa-sync` → **Private** → Create repository.
2. github.com/settings/personal-access-tokens/new (Fine-grained token):
   - Token name: `lampa-sync`, срок действия — максимальный;
   - Repository access: **Only select repositories** → `lampa-sync`;
   - Permissions → Repository permissions → **Contents: Read and write**;
   - Generate token → скопировать (`github_pat_…`).

**На каждом устройстве:** Настройки → «Торренты TV» → «Синхронизация через GitHub»:

- **Чей это телевизор** — имя человека латиницей, например `ya`. На всех устройствах одного человека — одинаковое, у других людей — своё (`mama`, `dacha`…);
- **Репозиторий** — `lampa-sync`;
- **Токен GitHub** — нажмите, откроется системная клавиатура Android (даже если в Lampa выбрана своя). На телефоне в приложении Google TV в режиме пульта нажмите значок клавиатуры и вставьте скопированный токен, затем «Готово». На экране от токена видны только последние 4 символа;
- «Синхронизировать сейчас» — внизу появится время и результат.

Дальше всё само: изменения с других устройств забираются при запуске Lampa, при возврате из плеера и раз в 10 минут. Свои изменения копятся и уходят одним коммитом не чаще раза в 10 минут — и сразу, когда вы уходите из Lampa (в плеер или выходите) или нажимаете «Синхронизировать сейчас». Если ничего не поменялось, коммита нет. В файле — только прогресс, отметки и короткие карточки закладок (название, постер, год, оценка): описание Lampa загрузит сама, когда карточку откроют.

Имя задаётся один раз на новом устройстве: если сменить его на телевизоре, где уже есть история, эта история уйдёт в папку нового имени. Все устройства с этим токеном технически могут читать все папки репозитория — для семьи это нормально. Токен хранится в Lampa на устройстве, на экране показываются только последние 4 символа. Когда срок токена закончится, создайте новый и вставьте его на устройствах.

## Аниме (Shikimori) — отдельный плагин

Второй плагин, ставится рядом с основным: Настройки → Расширения → «Добавить плагин» →

```
https://bregal1337.github.io/anime.js
```

**Раздел «Аниме Shikimori» в меню слева** — обычная главная Lampa со строками подборок Shikimori: онгоинги текущего сезона, анонсы следующего, прошлый сезон, популярное, лучшие сериалы и фильмы, жанры; после входа — «Смотрю», «Запланировано» (последние добавленные — первыми, как и в «Ещё»), «Отложено». На карточках — оценка Shikimori и русские названия. «Ещё» открывает подборку целиком — и карточка в конце строки, и кнопка в заголовке строки (с пульта: вверх с карточек строки), а кнопка «Фильтр» в шапке (вверх от сетки) меняет сезон (любой сезон, год или десятилетие), жанр, тип, статус и сортировку.

Карточка из подборки открывается обычной карточкой TMDB с кнопкой «Торренты»: продолжения находятся как сезоны одного сериала («Монолог фармацевта 3» → «Монолог фармацевта», экран торрентов сразу на 3-м сезоне). Сопоставление берётся из готовой карты Shikimori/MyAnimeList ↔ TMDB ([Fribb/anime-lists](https://github.com/Fribb/anime-lists), ~8300 тайтлов, сезоны как у трекеров) — она лежит на этом же сайте маленькими файлами (`anime-map/`) и раз в неделю обновляется сама. Тайтла нет в карте — поиск по японскому и полному названию с годом, потом как продолжение. Карта иногда ведёт на карточку TMDB, которой уже нет (у «Киберпанк: Бегущие по краю 2» — удалённый дубль): плагин сразу открывает карточку и параллельно проверяет, что она есть; если её нет — ищет по названию и открывает найденное, не найдено — открывает поиск. Сезоны, которых нет в карте, добираются из франшизы Shikimori, чтобы и для них работали статусы и отметки серий. На полной карточке любого аниме и в заголовке экрана торрентов показывается оценка Shikimori.

**Список Shikimori:**
- долгое OK на карточке аниме (или «Избранное» на странице) → «Shikimori: статус в списке» — Запланировано, Смотрю, Пересматриваю, Просмотрено, Отложено, Брошено или убрать; у сериала с несколькими сезонами плагин спросит, какой;
- досмотренные серии сами уходят в список: сезон сопоставляется с тайтлом Shikimori по дате выхода, число серий только растёт, после последней — «Просмотрено». Отключается в настройках.
- и обратно: при открытии сериала в «Торренты TV» серии, отмеченные на Shikimori, отмечаются просмотренными («Магическая битва»: 1 сезон «Просмотрено», 2 сезон 16 из 23 → экран открывается на 2 сезоне, 17 серии). Одно и то же число второй раз не переносится, поэтому снятая вручную отметка не вернётся;
- отметки на постерах — в разделе «Аниме», на главной, в поиске и подборках TMDB: ✓ просмотрено, ▶ 16/24 смотрю, ⏸ отложено, закладка — запланировано, ✕ брошено. Весь список Shikimori загружается одним запросом (600 тайтлов ≈ 170 КБ) при запуске Lampa и при входе в раздел, не чаще раза в 15 минут; на устройстве он занимает ~10 КБ, плюс файлы карты (~180 КБ на 600 тайтлов, обновляются раз в неделю). Свои изменения видны сразу. Настройки → «Аниме (Shikimori)» → «Обновить список Shikimori» — обновить сейчас.

**Подключить Shikimori один раз** (на телефоне или компьютере):

1. shikimori.io → Настройки → Приложения → «Новое приложение»: название `Lampa Anime`, Redirect URI `urn:ietf:wg:oauth:2.0:oob`, права `user_rates`.
2. В Lampa: Настройки → «Аниме (Shikimori)» → «Войти в Shikimori». На ТВ ничего вводить не нужно — всё вставляется на телефоне через ваш приватный репозиторий синхронизации на GitHub (если открылось приложение GitHub — выберите «Открыть в браузере»):
   - QR-код «Ключи Shikimori с телефона» → на телефоне откроется заготовка файла `shikimori_keys.txt` → вставьте Client ID и Client Secret после двоеточий → «Commit changes». Через несколько секунд ТВ заберёт ключи и покажет следующий QR-код;
   - QR-код «Вход в Shikimori» → войдите и нажмите «Разрешить», скопируйте код → на ТВ «Код с телефона» → новый QR-код → вставьте код в файл → «Commit changes». ТВ войдёт сам.
   
   Если назвали приложение на Shikimori не «Lampa Anime» — поправьте «Название приложения». Ввести ключи и код прямо на ТВ тоже можно (системная клавиатура), но вставка с телефона туда работает не везде.

Если в «Торренты TV» настроена синхронизация через GitHub, вход сохраняется в приватном репозитории (`<имя>/_extra/shikimori.json`), и на остальных устройствах этого человека он появляется сам (или кнопкой «Взять вход с другого устройства»). Доступ обновляется сам каждые сутки. Запросы к Shikimori идут не чаще 4 в секунду, с названием приложения, как требуют правила API.

## Настройки

Lampa → Настройки → «Торренты TV»: новый экран торрентов, экран фильма/сериала, предпочитаемое качество, запоминание фильтров, плитка серий, сброс любимых озвучек.

## Про запоминание момента

Прогресс хранится средствами Lampa (Timeline) и привязан к карточке, сезону и серии, поэтому не зависит от выбранной раздачи. Внешний плеер (MX Player, VLC) возвращает позицию в Lampa после закрытия. Если Android выгрузил Lampa из памяти во время просмотра, позиция серии теряется, но номер последней запущенной серии плагин помнит сам.

## Проверка на сохранённых тайтлах (tests/)

В `tests/corpus` — 35 сериалов (аниме и обычные), записанных один раз: карточка и серии TMDB, ответ парсера (те же запросы, что делает плагин) и франшиза Shikimori; магнет-ссылки не хранятся. `python tests/run.py` прогоняет на них код плагина в Chrome без окна — сезоны, части, раздачи каждого сезона, раскладку файлов по сериям (`tests/files.json`) — и показывает, что изменилось по сравнению с `tests/expect.json`. После проверенного изменения `python tests/run.py --update` принимает новый результат, `python tests/run.py Bleach` — показывает один тайтл, `--debug` — какие раздачи отсеяны и почему. `python tests/record.py Название` — записать тайтл заново.

Настоящие списки файлов — в `tests/files_real`: `python tests/record_files.py Bleach` берёт раздачи тайтла (с сидами) и через TorrServer на этом компьютере (http://127.0.0.1:8090) получает только список файлов, без загрузки видео, и удаляет торрент. Прогон проверяет на них, что серии, заявленные в названии раздачи, находятся среди её файлов — номера берутся так же, как их разбирает Lampa.
